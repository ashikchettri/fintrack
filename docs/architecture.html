FinTrack · household finance platform

How it fits together — UI to services to cloud

A React SPA and four Spring Boot services behind a reactive API gateway, packaged as containers and deployed to Kubernetes — running on Minikube today, with the GKE Autopilot path prepared. Requests flow top-to-bottom; identity and correlation IDs travel with them.

Platform & delivery

cross-cutting · code → cloud
Package

Containers

Multi-stage Docker: JDK build → Alpine JRE, non-root, layered jars. Trivy HIGH/CRITICAL gate in CI.

Orchestrate

Kubernetes

Helm chart (or raw Kustomize) — probes, resource limits, read-only FS. Minikube for dev, GKE Autopilot in cloud.

Managed data

Cloud SQL

Postgres 17 reached over localhost via the Cloud SQL Auth Proxy native sidecar — IAM-auth, no DB creds on the wire.

Secrets

Secret Manager + ESO

External Secrets Operator syncs Secret Manager → the k8s Secrets the pods mount, via Workload Identity.

Identity

Workload Identity

Pods act as a Google SA with no keys; GitHub Actions deploys via Workload Identity Federation (OIDC).

Deliver

CI/CD

GitHub Actions: build, test, coverage gates, secret & image scan on every PR; tag → build/push to Artifact Registry → helm upgrade.

Provision

Terraform

GKE, Cloud SQL, Artifact Registry, IAM/WIF, reserved IP, and a monthly billing budget — all as code.

Operate

Observability

Actuator liveness/readiness probes; one X-Request-Id across services into logs and every error body (ADR 010).

What it does

product features

Households & privacy

Everyone's finances in one view; transactions personal by default, shared only by opt-in.

CSV → dashboard

The hero flow: upload a bank statement, get deduplicated transactions and an instant dashboard.

AI categorization

Claude sorts transactions into a canonical taxonomy, with a rule-based fallback.

Budgets vs actual

Household income/expense/savings budget, compared per canonical category.

Home loan & cash flow

Payoff calculator, monthly surplus, and an affordability what-if.

Shared commitments

Opt specific costs into a shared view with an equal-split settlement.

Net worth

A manual balance sheet that folds in the home loan for a real figure.

AI insights & Q&A

Monthly spending summary and grounded natural-language answers about your money.
