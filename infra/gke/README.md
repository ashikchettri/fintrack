# FinTrack on GKE

Terraform for the Google Cloud foundation — GKE Autopilot, Artifact Registry,
Cloud SQL, Secret Manager, and keyless identity (Workload Identity + WIF).
See **ADR 017**. Provisioning **costs money** and is run by you against a
**dedicated** project.

> ⚠️ `terraform.tfvars`'s `project_id` must be a **dedicated FinTrack project** —
> never a shared or production project for something else.

## 1. Provision (Terraform / OpenTofu)

```bash
gcloud auth application-default login
gcloud projects create fintrack-<suffix>          # a fresh project
gcloud billing projects link fintrack-<suffix> --billing-account=<ACCT>

cd infra/gke/terraform
cp terraform.tfvars.example terraform.tfvars       # set project_id
terraform init
terraform apply                                    # creates the cluster, DB, registry, IAM…
terraform output                                   # registry URL, cluster, SAs, WIF provider, DB conn name
```

## 2. Add the out-of-band secrets

Terraform creates the secret *containers*; add the sensitive values yourself:

```bash
# JWT signing key (PKCS#8 PEM) — required outside local (ADR 002)
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out jwt-signing.pem
gcloud secrets versions add fintrack-jwt-signing-key   --data-file=jwt-signing.pem

# Anthropic key (optional — enables AI features; empty = rule/template fallback)
printf '%s' "$ANTHROPIC_API_KEY" | gcloud secrets versions add fintrack-anthropic-api-key --data-file=-
```

(The DB password is already generated by Terraform and stored in
`fintrack-db-password`.)

## 3. Wire the deploy (next PRs)

The cluster is ready; deploying the app needs the pieces called out in ADR 017:

- a **Cloud SQL Auth Proxy sidecar** + Secret Manager mounting (CSI driver /
  External Secrets) in the Helm chart, and a concrete `values-gke.yaml`,
- a **GCE Ingress + managed certificate**,
- a **`deploy-gke.yml`** workflow: authenticate via WIF
  (`workload_identity_provider` = the `wif_provider` output, `service_account` =
  the `deployer_service_account` output), build/scan/push each image to
  Artifact Registry, then `helm upgrade` with `image.registry` set to the
  `artifact_registry` output.

Set these Terraform outputs as GitHub **repository variables** for that workflow:
`GCP_PROJECT`, `GCP_REGION`, `WIF_PROVIDER`, `DEPLOYER_SA`, `GKE_CLUSTER`.

## Tear down

```bash
cd infra/gke/terraform && terraform destroy      # stops the Autopilot + Cloud SQL charges
```
